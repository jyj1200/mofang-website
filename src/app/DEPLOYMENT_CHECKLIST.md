## 🔧 问题排查

### 问题1：提交表单后没有收到邮件
**可能原因：**
- RESEND_API_KEY 未配置
- 邮箱地址填写错误
- 邮件被垃圾邮件过滤

**解决方法：**
1. 检查服务器日志
2. 确认环境变量 `RESEND_API_KEY` 已设置
3. 检查垃圾邮件文件夹
4. 确认公司邮箱可以正常接收邮件

### 问题2：管理后台无数据
**可能原因：**
- 数据库连接失败
- API端点配置错误

**解决方法：**
1. 打开浏览器开发者工具（F12）
2. 查看 Console 和 Network 标签
3. 检查是否有错误信息
4. 确认 API 请求返回正确数据

### 问题3：表单提交失败
**可能原因：**
- 网络连接问题
- 服务器错误
- 必填字段未填写

**解决方法：**
1. 确认网络连接正常
2. 检查浏览器控制台错误信息
3. 确认所有必填项已填写
4. 重试提交
