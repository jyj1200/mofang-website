## 🖥️ 管理后台使用

### 访问后台
```
浏览器输入：https://您的域名.com/admin-dashboard
```

### 查看咨询列表
后台显示所有客户提交的咨询，包括：
- ⏰ 提交时间
- 🏷️ 类型（工业设计 / 文创产品）
- 👤 客户姓名
- 🏢 公司名称
- 📞 联系方式

### 搜索和筛选
- **搜索框**：输入姓名、公司或电话快速查找
- **筛选按钮**：
  - 全部
  - 工业设计
  - 文创产品

### 查看详情
1. 点击任意咨询记录的"查看详情"按钮
2. 弹出窗口显示完整信息
3. 可以直接点击"发送邮件"或"拨打电话"

### 导出数据
- 点击右上角"导出"按钮
- 自动下载CSV文件
- 文件包含所有筛选后的咨询记录
